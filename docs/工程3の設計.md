# 工程3の設計（構造化）

会議録（工程2の Markdown）を、発言、目次、会派の名簿、質問者ごとのまとまりに分ける工程の設計と結果（2026年11月15日）。工程5で AI が読む単位（1人分の質問と、それへの全答弁）は、ここで作る。AI は使わず、すべてコードでやる。全体の作り方は [作り方.md](作り方.md)、スクリプトの使い方は [動かし方.md](動かし方.md) の「工程3 構造化」。

文中の T1〜T6 はスクリプトに当たる。

| | スクリプト | 作るもの |
|---|---|---|
| T1 | `pipeline/03a_speeches.mjs` | 発言、会議の目録、発言者の一覧 |
| T2 | `pipeline/03b_toc.mjs` | 目次 |
| T3 | `pipeline/03c_members.mjs` | 会派の名簿（任期×氏名→会派）の検証と根拠 |
| T4 | `pipeline/03d_plenary.mjs` | 本会議のまとまり |
| T5 | `pipeline/03e_committee.mjs` | 委員会のまとまり |
| T6 | `pipeline/03f_summary.mjs` | 全体の件数と、出力をまたいだ確かめ（何も書き出さない） |

## 共通の約束

共通の関数は `pipeline/lib.mjs` に置く。

- 氏名: 全角・半角の空白を除き、末尾の「議員」「委員」を外す（`林　清治委員` → `林清治`）。`normalizeName`。表記ゆれは `aliases.csv` で寄せる（T4・T5 が会派を引くとき）
- 出典のリンク: `speechUrl(会議の閲覧URL, HUID)`
- 任期: 選挙の年の5月1日から4年。`2023-2027` の形。2007年1〜4月は `2003-2007`。`termOf`
- 会期: `2024-1定`、`2024-1臨`。年は会議の日付の年。`sessionOf`
- ファイルの指し方: `data/md` からの相対パス（`2024/2024-02-20_k1_4349.md`）
- スクリプトは何度流しても同じ結果になるようにする。最後に検証の項目ごとの件数を出し、0件でないものは例を20件まで出す（工程2と同じ）
- `data/` の中身をそのまま読み込まない。件数や中身はスクリプトで数えて確かめる

## 各層の項目

### 発言 `speeches/<年>.jsonl`（T1）

| 項目 | 内容 |
|---|---|
| `huid` | 会議録システムの発言ID（数値） |
| `file`, `seq` | ファイルと、その中での順番（1から） |
| `date`, `kind` | 日付、種別（定例会、臨時会、委員会） |
| `mark` | ○ ◆ ◎ |
| `role` | 役職から決める。`chair`（議長、副議長、委員長、副委員長など）、`member`（議員、委員）、`official`（市長、局長など） |
| `name`, `title` | 氏名（正規化済み。委員会の答弁者は姓だけ）、役職（`議員`、`委員`、`市長`、`財政部長` など） |
| `note` | `委員（関連）` の「関連」など、役職の後ろの括弧書き |
| `head` | 発言者の部分の原文（確認用） |
| `joined` | 姓と役職のあいだに空白がなく分けられなかったもの（`title` に姓ごと入れ、`name` は空）。2019年10月16日の1日分の14件だけ |
| `text` | 発言の原文（発言者の部分を含む）。Markdown の空行を除いたもの |
| `chars` | 文字数 |

### 会議 `meetings.jsonl`（T1）

`file`、`kind`、`fino`、`meeting`（原文の会議名）、`label`、`issue`（`02号`、`記録`、`目次`）、`date`、`session`、`term`、`committee`（年号を外した委員会名）、`committee_type`（常任、予算特別、決算特別、議案審査特別、調査特別、議会運営、その他）、`viewer`（閲覧URL）、`speeches`（発言数）。

委員会の `session` は、日付がその会期（初日から最終日まで）に入っていればその会期。入っていなければ空（閉会中）。

### 目次 `toc.jsonl`（T2）

1号が1行。T4・T5 が使う最低限の項目は次のとおり。ほかの項目は T2 が足してよい。

- 本会議: `toc_file`、`session`、`issue`、`date`、`entries`。`entries` は議事の並びで、1件ごとに `type`（代表質問、討論、委員長報告、文書質問 など）、`name`、`faction`（目次の略称のまま）、`items`（大項目）、`answerers`
- 特別委員会: `toc_file`、`committee`、`issue`、`date`、`entries`。`entries` は議題ごとに `agenda` と、質疑者と答弁者の並び `speakers`（`name`、`title`）

T2 で作ったもの（2026年11月15日）。上の最低限の項目に、次を足した。

| 項目 | 内容 |
|---|---|
| `file` | その号の会議録（日のファイル）。`meetings.jsonl` の会議名と号で引いた。全1,230号で見つかり、日付も一致した。T4・T5 はこれで `speeches/` と結ぶ |
| `kind`, `meeting`, `term`, `committee_type` | `meetings.jsonl` と同じ値 |
| `issue` | `02号` の形（`meetings.jsonl` の `issue` と同じ）。懲罰特別委員会の目次の「第１回」も `01号` にした |

本会議の `entries` は、1件ごとに次の項目を持つ（使わない項目は `null` か空の配列）。

| 項目 | 内容 |
|---|---|
| `type` | 代表質問、質疑、討論、委員長報告、提案説明、文書質問、動議、挨拶、意見陳述、発言、報告、その他 |
| `agenda` | 直前の日程（「日程第２　議案第１号から第56号まで、諮問第１号」）。休憩・散会などの進行の項目では変えない |
| `name`, `title` | 質問者は氏名（`normalizeName` 済み）と `議員`。答弁者、委員長報告、提案説明は目次の書き方のまま姓だけ（`秋元`／`市長`、`藤田`／`総務委員長`）。同姓の議員は `伊藤（理）` のように括弧付き |
| `faction` | 代表質問・質疑・討論で、目次の「氏名議員（会派）」の括弧の中（略称のまま。討論は書かれていないことが多い） |
| `items` | 代表質問・質疑の大項目。会派の2人で分担したときは「（宗形）都市環境と防災」のように担当の姓が前に付く（2019年第4回定例会。本文では質問者1人がまとめて読んでいる） |
| `answerers` | 「答弁」の見出しの下の並び（`name` は姓、`title` は役職） |
| `followups` | 再質問・再々質問・再質疑の並び。質問者と答弁者が交互に入る（`stage` に見出し） |
| `note` | 動議の中身（「会期を42日間と設定」「決定」）、「報告・提案説明」の「提案説明」など |

特別委員会の `entries` は、議題（目次の「１　第２款　総務費　第４項　選挙費」）ごとに1件。`type` は、質疑、議題（質疑者のいない議題）、討論、発言、説明、参考人発言、意見表明、その他。`speakers` は `mark`（`●` 質疑する側、`〇` 答弁する側）、`name`、`title`、`note`（「動議」など）。休憩をはさんだ「質疑続行」は、同じ議題の `speakers` の続きに入れた。最終日の討論のように議題のないものは `agenda` が `null`。「（柿崎委員の質疑保留）」などの注記は `notes` に入れた。

数（2026年11月15日）: 目次206件、号1,230件（本会議493、特別委員会737）。代表質問486人分（T4 で直したあと。直す前は465人分）、文書質問84件（50会期。同じ会期の第1号と第2号に同じ議員が出てくるものがある）、委員長報告794件、討論622件。特別委員会は `entries` が1,673件（うち質疑1,270、質疑者のいない議題278）、発言者の行が20,459行。

T4 で直したこと（2026年11月15日）: 休憩・再開をはさむと、代表質問の文脈が切れていた。再開のあとに「代表質問の続行」の見出しなしで出てくる質問者（無所属・1人会派の議員の「質問」。2010〜2025年の21人分）が「その他」になって大項目が落ち、その人の答弁者と再質問が1つ前の質問者に付いていた。`03b_toc.mjs` で、休憩宣告・再開宣告・議長交代・会議時間の延長では、代表質問・質疑・答弁・討論の文脈を切らないようにした（動議の文脈は切る）。直したあとも、委員会の目次は1行も変わらず、T5 の出力も1バイトも変わらない。T3 の検証も、根拠（会派を名乗った箇所）が2件増えただけで結果は同じ。

T4・T5 が気をつけること:

- 目次の書き方は20年で少しずつ違う。2019年の数回分は「１．」でなく「１　」、2008年の議案審査特別委員会は「１．」。見出しの抜け（答弁・再質問のあとに「代表質問の続行」がないまま次の質問者が出てくる、33件。T4 で直した休憩・再開のあとの21件を含む）は、会派付きの議員が出てきたところで次の代表質問として読んだ。どれもスクリプトの最後に（参考）として一覧を出す
- 2016年第1回定例会の第5号は、目次に「２月23日から２月25日までの代表質問において、市長に答弁を求めるとした項目のみ」とある代表質問で、同じ会期に同じ質問者が2回出てくる
- 答弁者の姓と役職は、`speakers.jsonl` の同じ任期の発言者と突き合わせて分けた。分けられなかった14件は、目次の誤字（「金谷雇用促進部長」「柴田丸山動物園長」など）で、`name` が `null`、`title` に原文のまま入っている
- 抜き取りではなく全件で、目次の人名がその日の会議録の発言者にいるかを確かめた。質問者・質疑者は 9,887 / 9,890 件が一致し、合わないのは会議録の本文の誤字（「森喜誉則」「脇元之」）。答弁者は 13,656 / 13,693 件が一致し、合わないのは議員の◎答弁（突き合わせの側の都合）と、目次・本文の誤字や役職の書き方の違い。表記ゆれは T3 の `aliases.csv` で寄せる

### まとまり `exchanges/<年>-k<種別>.jsonl`（T4・T5）

```json
{ "id": 243412,
  "type": "代表質問",
  "file": "2024/2024-02-20_k1_4349.md", "date": "2024-02-20", "kind": "定例会",
  "session": "2024-1定", "term": "2023-2027", "committee": null,
  "agenda": "日程第２ 議案第１号から第36号まで…",
  "questioner": "川田ただひさ", "faction": "自由民主党議員会", "related_to": null,
  "items": ["市長の政治姿勢", "物価高騰や労務費上昇を受けての事業者支援", "…"],
  "answerers": [{ "title": "市長", "name": "秋元克広" }, { "title": "副市長", "name": "町田隆敏" }],
  "huids": [243412, 243413, 243414],
  "chars": 25000,
  "url": "https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&…&HUID=243412&KGNO=609&FINO=4349" }
```

- `id` は最初の発言（質問者の発言）の HUID。出典にそのまま使える。`url` はその発言の閲覧URL（`speechUrl`）
- `type`: 代表質問、質疑、討論、委員長報告、説明（提案説明、理事者の説明）、文書質問、その他。本会議か委員会かは `kind` でわかる
- `huids` には範囲内の発言をすべて入れる（議長・委員長の進行も含む）。原文は持たせない。工程5で `speeches` から組み立てる
- `faction` は `members.csv` から引く。名簿がまだなければ空にして、名簿ができてから流し直す
- `items` は本会議の代表質問・質疑だけ（目次の大項目。質疑は目次に大項目があるものだけ入り、なければ空の配列）。ほかは `null`
- `answerers` の役職は原文のまま持たせる。局への対応づけは、工程5で要るとわかってから考える
- `committee_type` は T5 が足した項目（`meetings.jsonl` と同じ）。T4 も同じ項目を持たせ、本会議は `null`
- 文書質問は、まとまりにしない（T4 で調べると、質問と答弁書の本文が会議録にない。下の「T4 の結果」）

### 会派の名簿 `pipeline/members/`（T3）

- `members.csv`: `term,name,faction,from,to,ward,source`。`faction` は正式名。任期の途中で会派を移った人は、期間（`from`、`to`）を分けて2行にする。`ward` は選出区（`北区` など。外部の名簿から。工程5以降で地域の軸に使える）。`source` は根拠を空白区切りで（Wayback の URL、`huid:243412`、`toc:2024/2024-02-14_k1_4342.md`）
- `name` はその任期の会議録の書き方（`speakers.jsonl` と同じ）。任期が違えば同じ人でも別の行で、書き方が変わることもある（`小嶋裕美` → `こじまゆみ`）
- `from`・`to` は、任期を通して在任していれば任期の初日（5月1日）と末日（4月30日）。会派が変わった日は「新しい会派を最初に確かめられた日」（名簿のページの更新日、または会議録で名乗った日）で、実際に移った日はそれより前のことがある。任期の途中で入った・辞めた人は、出席議員の欄に最初・最後に出た日（亡くなった日・補欠選挙の日が会議録でわかる4人は、その日に直した）
- 引くときは (`term`, 氏名, 日付) で、`from` ≦ 日付 ≦ `to` の行を探す。氏名は先に `aliases.csv` で寄せる。期間に切れ目はない（`03c_members.mjs` が確かめる）
- `factions.csv`: `faction,aliases,terms`。正式名と、目次の略称・旧称（`;` 区切り）。正式名は外部の名簿の見出しから先頭の「札幌市議会」を外したもの（`札幌市議会自由民主党議員会` → `自由民主党議員会`）。改称した会派は別の行にする（`民主党・市民連合議員会` → `民主市民連合議員会` → `民進党市民連合議員会` → `民主市民連合議員会`）。同じ呼び方が任期によって別の会派を指すので、呼び方を引くときは `terms` で絞る
- `factions.csv` には2026年11月18日に4列目 `lineage`（系列）を足した。名前だけ変えた会派に、いまの名前を書く（`民主党・市民連合` → `民主市民連合議員会` など。合わさった・分かれた会派は空のまま）。工程7で、名前の変わった会派を1つにまとめるのに使う（`lib.mjs` の `loadLineages`）
- `aliases.csv`: `variant,name,source`。会議録に出てくる別の表記と、`members.csv` の氏名。`speakers.jsonl` で、同じ任期に似た名前があるもの（発言が数件しかないほう）を調べて作る
- 2003〜2007年の任期の分（2007年1〜4月）も、会議録に出てくるので名簿に入れる。ほかの任期より後回しでよい

## まとまりの区切り方

### 本会議（T4）

- 1人分の範囲: 議長がある議員を指名してから、次に別の議員を指名するまで。質問、答弁、再質問、再々質問をすべて含む
- 休憩では区切らない。休憩で切ると1人分が2つに割れることを、仮の集計で確認した
