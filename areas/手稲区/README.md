# 手稲区から辿る札幌市議会（2007〜2026年）

札幌市議会の会議録（本会議と委員会）を AI が項目ごとに要約した記録 54,813件のうち、地域に手稲区が付いたもの 721件を、話題ごと・地名ごとに並べた。話題の20年の流れ（札幌市全体）は、各話題の「20年の経緯」から読める。

> 要旨は AI が会議録を要約したもので、原文ではない。数字や答弁を人前で使う前に、各記録の [会議録] のリンクで原文を確かめる。地域も AI が付けたもので、「全市」の話の中で手稲区に具体的に触れたものにも付いている。会議録は2026年6月ごろの分まで。

- 話題の一覧（札幌市全体）: [topics/README.md](../../topics/README.md)
- ほかの区: [10区の一覧](../README.md)
- 地名ごと: [手稲区の記録に出てくる地名](地名.md)（276個。3ファイルに分けた。多いもの: [ていねプール](%E5%9C%B0%E5%90%8D.md#%E3%81%A6%E3%81%84%E3%81%AD%E3%83%97%E3%83%BC%E3%83%AB)（50件）、[手稲山口地区](%E5%9C%B0%E5%90%8D.md#%E6%89%8B%E7%A8%B2%E5%B1%B1%E5%8F%A3%E5%9C%B0%E5%8C%BA)（49件）、[山口処理場](%E5%9C%B0%E5%90%8D.md#%E5%B1%B1%E5%8F%A3%E5%87%A6%E7%90%86%E5%A0%B4)（31件）、[手稲山口](%E5%9C%B0%E5%90%8D.md#%E6%89%8B%E7%A8%B2%E5%B1%B1%E5%8F%A3)（27件）、[手稲山](%E5%9C%B0%E5%90%8D.md#%E6%89%8B%E7%A8%B2%E5%B1%B1)（24件）、[手稲中学校](%E5%9C%B0%E5%90%8D.md#%E6%89%8B%E7%A8%B2%E4%B8%AD%E5%AD%A6%E6%A0%A1)（21件）、[山本地区](%E5%9C%B0%E5%90%8D.md#%E5%B1%B1%E6%9C%AC%E5%9C%B0%E5%8C%BA)（17件）、[手稲](%E5%9C%B0%E5%90%8D.md#%E6%89%8B%E7%A8%B2)（17件））
