# 区から辿る

札幌市議会の会議録（本会議と委員会）を AI が項目ごとに要約した記録 54,813件を、地域（区）ごとに、話題ごと・地名ごとに並べた。区の名前から入口を開く。

> 地域は AI が付けたもので、「全市」の話の中で区に具体的に触れたものにも、その区が付いている。1つの記録に2つ以上の区が付くこともあるので、区ごとの数を足しても記録の数にはならない。会議録は2026年6月ごろの分まで。
