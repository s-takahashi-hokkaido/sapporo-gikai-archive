# 東区から辿る札幌市議会（2007〜2026年）

札幌市議会の会議録（本会議と委員会）を AI が項目ごとに要約した記録 54,813件のうち、地域に東区が付いたもの 1,671件を、話題ごと・地名ごとに並べた。話題の20年の流れ（札幌市全体）は、各話題の「20年の経緯」から読める。

> 要旨は AI が会議録を要約したもので、原文ではない。数字や答弁を人前で使う前に、各記録の [会議録] のリンクで原文を確かめる。地域も AI が付けたもので、「全市」の話の中で東区に具体的に触れたものにも付いている。会議録は2026年6月ごろの分まで。

- 話題の一覧（札幌市全体）: [topics/README.md](../../topics/README.md)
- ほかの区: [10区の一覧](../README.md)
- 地名ごと: [東区の記録に出てくる地名](地名.md)（535個。多いもの: [丘珠空港](%E5%9C%B0%E5%90%8D.md#%E4%B8%98%E7%8F%A0%E7%A9%BA%E6%B8%AF)（427件）、[モエレ沼公園](%E5%9C%B0%E5%90%8D.md#%E3%83%A2%E3%82%A8%E3%83%AC%E6%B2%BC%E5%85%AC%E5%9C%92)（88件）、[東雁来](%E5%9C%B0%E5%90%8D.md#%E6%9D%B1%E9%9B%81%E6%9D%A5)（80件）、[新千歳空港](%E5%9C%B0%E5%90%8D.md#%E6%96%B0%E5%8D%83%E6%AD%B3%E7%A9%BA%E6%B8%AF)（58件）、[苗穂駅](%E5%9C%B0%E5%90%8D.md#%E8%8B%97%E7%A9%82%E9%A7%85)（54件）、[札幌駅](%E5%9C%B0%E5%90%8D.md#%E6%9C%AD%E5%B9%8C%E9%A7%85)（45件）、[東雁来第２地区](%E5%9C%B0%E5%90%8D.md#%E6%9D%B1%E9%9B%81%E6%9D%A5%E7%AC%AC%EF%BC%92%E5%9C%B0%E5%8C%BA)（35件）、[さとらんど](%E5%9C%B0%E5%90%8D.md#%E3%81%95%E3%81%A8%E3%82%89%E3%82%93%E3%81%A9)（31件））
