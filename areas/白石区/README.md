# 白石区から辿る札幌市議会（2007〜2026年）

札幌市議会の会議録（本会議と委員会）を AI が項目ごとに要約した記録 54,813件のうち、地域に白石区が付いたもの 1,193件を、話題ごと・地名ごとに並べた。話題の20年の流れ（札幌市全体）は、各話題の「20年の経緯」から読める。

> 要旨は AI が会議録を要約したもので、原文ではない。数字や答弁を人前で使う前に、各記録の [会議録] のリンクで原文を確かめる。地域も AI が付けたもので、「全市」の話の中で白石区に具体的に触れたものにも付いている。会議録は2026年6月ごろの分まで。

- 話題の一覧（札幌市全体）: [topics/README.md](../../topics/README.md)
- ほかの区: [10区の一覧](../README.md)
- 地名ごと: [白石区の記録に出てくる地名](地名.md)（398個。2つのファイルに分けた。多いもの: [白石区複合庁舎](%E5%9C%B0%E5%90%8D.md#%E7%99%BD%E7%9F%B3%E5%8C%BA%E8%A4%87%E5%90%88%E5%BA%81%E8%88%8E)（66件）、[白石区役所](%E5%9C%B0%E5%90%8D.md#%E7%99%BD%E7%9F%B3%E5%8C%BA%E5%BD%B9%E6%89%80)（53件）、[白石清掃工場](%E5%9C%B0%E5%90%8D.md#%E7%99%BD%E7%9F%B3%E6%B8%85%E6%8E%83%E5%B7%A5%E5%A0%B4)（46件）、[白石営業所](%E5%9C%B0%E5%90%8D.md#%E7%99%BD%E7%9F%B3%E5%96%B6%E6%A5%AD%E6%89%80)（32件）、[南郷通](%E5%9C%B0%E5%90%8D.md#%E5%8D%97%E9%83%B7%E9%80%9A)（25件）、[菊水上町](%E5%9C%B0%E5%90%8D.md#%E8%8F%8A%E6%B0%B4%E4%B8%8A%E7%94%BA)（22件）、[地下鉄白石駅](%E5%9C%B0%E5%90%8D.md#%E5%9C%B0%E4%B8%8B%E9%89%84%E7%99%BD%E7%9F%B3%E9%A7%85)（22件）、[東札幌駅](%E5%9C%B0%E5%90%8D.md#%E6%9D%B1%E6%9C%AD%E5%B9%8C%E9%A7%85)（22件））
