# 豊平区から辿る札幌市議会（2007〜2026年）

札幌市議会の会議録（本会議と委員会）を AI が項目ごとに要約した記録 54,813件のうち、地域に豊平区が付いたもの 882件を、話題ごと・地名ごとに並べた。話題の20年の流れ（札幌市全体）は、各話題の「20年の経緯」から読める。

> 要旨は AI が会議録を要約したもので、原文ではない。数字や答弁を人前で使う前に、各記録の [会議録] のリンクで原文を確かめる。地域も AI が付けたもので、「全市」の話の中で豊平区に具体的に触れたものにも付いている。会議録は2026年6月ごろの分まで。

- 話題の一覧（札幌市全体）: [topics/README.md](../../topics/README.md)
- ほかの区: [10区の一覧](../README.md)
