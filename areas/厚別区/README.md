# 厚別区から辿る札幌市議会（2007〜2026年）

札幌市議会の会議録（本会議と委員会）を AI が項目ごとに要約した記録 54,813件のうち、地域に厚別区が付いたもの 978件を、話題ごと・地名ごとに並べた。話題の20年の流れ（札幌市全体）は、各話題の「20年の経緯」から読める。

> 要旨は AI が会議録を要約したもので、原文ではない。数字や答弁を人前で使う前に、各記録の [会議録] のリンクで原文を確かめる。地域も AI が付けたもので、「全市」の話の中で厚別区に具体的に触れたものにも付いている。会議録は2026年6月ごろの分まで。

- 話題の一覧（札幌市全体）: [topics/README.md](../../topics/README.md)
- ほかの区: [10区の一覧](../README.md)
- 地名ごと: [厚別区の記録に出てくる地名](地名.md)（380個。3ファイルに分けた。多いもの: [新さっぽろ駅](%E5%9C%B0%E5%90%8D.md#%E6%96%B0%E3%81%95%E3%81%A3%E3%81%BD%E3%82%8D%E9%A7%85)（52件）、[もみじ台](%E5%9C%B0%E5%90%8D.md#%E3%82%82%E3%81%BF%E3%81%98%E5%8F%B0)（51件）、[厚別山本公園](%E5%9C%B0%E5%90%8D.md#%E5%8E%9A%E5%88%A5%E5%B1%B1%E6%9C%AC%E5%85%AC%E5%9C%92)（38件）、[下野幌団地](%E5%9C%B0%E5%90%8D.md#%E4%B8%8B%E9%87%8E%E5%B9%8C%E5%9B%A3%E5%9C%B0)（34件）、[新さっぽろ駅周辺地区](%E5%9C%B0%E5%90%8D.md#%E6%96%B0%E3%81%95%E3%81%A3%E3%81%BD%E3%82%8D%E9%A7%85%E5%91%A8%E8%BE%BA%E5%9C%B0%E5%8C%BA)（33件）、[もみじ台団地](%E5%9C%B0%E5%90%8D.md#%E3%82%82%E3%81%BF%E3%81%98%E5%8F%B0%E5%9B%A3%E5%9C%B0)（28件）、[新さっぽろ駅周辺](%E5%9C%B0%E5%90%8D.md#%E6%96%B0%E3%81%95%E3%81%A3%E3%81%BD%E3%82%8D%E9%A7%85%E5%91%A8%E8%BE%BA)（26件）、[白石営業所](%E5%9C%B0%E5%90%8D.md#%E7%99%BD%E7%9F%B3%E5%96%B6%E6%A5%AD%E6%89%80)（26件））
