## 20年の経緯

### 2007〜2011年　コールセンターと電子申請の導入

2007年10月、民主党・市民連合の桑原透議員が情報弱者に配慮した電子自治体の推進を求め、情報化推進部長はコールセンターの平成18年度の利用が9万5,556件だったと答え、簡易電子申請サービスを平成20年度中に導入する目標を示した（[2007-10-25](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2007&TYY=2007&TITL_SUBT=%95%BD%90%AC%82P%82X%94N%91%E6%88%EA%95%94%8C%88%8EZ%93%C1%95%CA%88%CF%88%F5%89%EF%81%7C10%8C%8E25%93%FA-07%8D%86&HUID=94308&KGNO=259&FINO=1922)）。2008年2月、自由民主党議員会の佐々木みつこ議員がｅＬＴＡＸの利用拡大や電子納税システムの導入を問い、税政部長は電子納税を費用対効果の面から見送ったとし、調査検討するとした（[2008-02-29](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2008&TYY=2008&TITL_SUBT=%95%BD%90%AC%82Q%82O%94N%91%E6%88%EA%95%94%97%5C%8EZ%93%C1%95%CA%88%CF%88%F5%89%EF%81%7C02%8C%8E29%93%FA-02%8D%86&HUID=96903&KGNO=269&FINO=1978)）。2008年3月、情報化推進部長はコールセンターの今年度の利用が10万件を超えたと答え、区役所電話交換業務との統合に向けて横断的な検討を行うとした（[2008-03-18](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2008&TYY=2008&TITL_SUBT=%95%BD%90%AC%82Q%82O%94N%91%E6%88%EA%95%94%97%5C%8EZ%93%C1%95%CA%88%CF%88%F5%89%EF%81%7C03%8C%8E18%93%FA-07%8D%86&HUID=98364&KGNO=269&FINO=1989)）。2010年10月、情報化推進部長は利用者の減少した市民情報センターを平成22年度末で廃止すると答えた（[2010-10-08](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2010&TYY=2010&TITL_SUBT=%95%BD%90%AC%82Q%82Q%94N%91%E6%88%EA%95%94%8C%88%8EZ%93%C1%95%CA%88%CF%88%F5%89%EF%81%7C10%8C%8E08%93%FA-03%8D%86&HUID=122791&KGNO=314&FINO=2392)）。
