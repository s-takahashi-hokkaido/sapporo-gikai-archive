## 20年の経緯

### 2007〜2011年　パートナーシップ排雪の費用負担見直し

パートナーシップ排雪では市の負担割合が想定の5対5を超えていることが論点となった（[2007-10-23](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2007&TYY=2007&TITL_SUBT=%95%BD%90%AC%82P%82X%94N%91%E6%93%F1%95%94%8C%88%8EZ%93%C1%95%CA%88%CF%88%F5%89%EF%81%7C10%8C%8E23%93%FA-06%8D%86&HUID=94151&KGNO=260&FINO=1921)、[2008-03-13](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2008&TYY=2008&TITL_SUBT=%95%BD%90%AC%82Q%82O%94N%91%E6%93%F1%95%94%97%5C%8EZ%93%C1%95%CA%88%CF%88%F5%89%EF%81%7C03%8C%8E13%93%FA-06%8D%86&HUID=98246&KGNO=270&FINO=1988)）。財政部長は、地域負担額を固定しているため市の支出割合が年により７割を超えるとし、制度見直しを行財政改革プラン案に計上したと答えた（[2007-10-11](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2007&TYY=2007&TITL_SUBT=%95%BD%90%AC%82P%82X%94N%81i%8F%ED%94C%81j%91%8D%96%B1%88%CF%88%F5%89%EF%81%7C10%8C%8E11%93%FA-%8BL%98^&HUID=92567&KGNO=243&FINO=1909)）。雪対策室長は、負担割合がおおむね地域側が３、行政側が７になっている要因を排雪量の増加や運搬距離の延長だと説明し、見直しの効果額は６億300万円とされた（[2007-10-23](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2007&TYY=2007&TITL_SUBT=%95%BD%90%AC%82P%82X%94N%91%E6%93%F1%95%94%8C%88%8EZ%93%C1%95%CA%88%CF%88%F5%89%EF%81%7C10%8C%8E23%93%FA-06%8D%86&HUID=94151&KGNO=260&FINO=1921)）。2008年3月、雪対策室長は市民助成トラックとの一元化も含めて検討すると答えたが、記録上は結論に至っていない（[2008-03-13](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2008&TYY=2008&TITL_SUBT=%95%BD%90%AC%82Q%82O%94N%91%E6%93%F1%95%94%97%5C%8EZ%93%C1%95%CA%88%CF%88%F5%89%EF%81%7C03%8C%8E13%93%FA-06%8D%86&HUID=98246&KGNO=270&FINO=1988)、[2010-11-24](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2010&TYY=2010&TITL_SUBT=%95%BD%90%AC%82Q%82Q%94N%81i%8F%ED%94C%81j%8C%9A%90%DD%88%CF%88%F5%89%EF%81%7C11%8C%8E24%93%FA-%8BL%98^&HUID=124653&KGNO=301&FINO=2416)）。

### 2008〜2011年　排雪量の抑制と社会実験

2008年9月、加藤副市長は排雪量の抑制など、できるものから順次取り組むと答えた（[2008-09-30](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=1&FYY=2008&TYY=2008&TITL_SUBT=%95%BD%90%AC%82Q%82O%94N%91%E6%81@%82R%89%F1%92%E8%97%E1%89%EF%81%7C09%8C%8E30%93%FA-03%8D%86&HUID=102112&KGNO=276&FINO=2053)）。2010年11月、市は平成24年度の生活道路の抑制目標を64万立方メートルとし、今冬から社会実験を行うと説明した（[2010-11-24](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2010&TYY=2010&TITL_SUBT=%95%BD%90%AC%82Q%82Q%94N%81i%8F%ED%94C%81j%8C%9A%90%DD%88%CF%88%F5%89%EF%81%7C11%8C%8E24%93%FA-%8BL%98^&HUID=124653&KGNO=301&FINO=2416)）。社会実験は、パートナーシップ制度を実施していた町内会などで交差点排雪をシーズン２回程度行うものである（[2010-11-24](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2010&TYY=2010&TITL_SUBT=%95%BD%90%AC%82Q%82Q%94N%81i%8F%ED%94C%81j%8C%9A%90%DD%88%CF%88%F5%89%EF%81%7C11%8C%8E24%93%FA-%8BL%98^&HUID=124662&KGNO=301&FINO=2416)）。2011年2月、公明党議員会の涌井委員が残された雪山の危険性を指摘し、雪対策室長は今冬の状況を検証して対応策を検討するとした（[2011-02-21](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2011&TYY=2011&TITL_SUBT=%95%BD%90%AC%82Q%82R%94N%81i%8F%ED%94C%81j%8C%9A%90%DD%88%CF%88%F5%89%EF%81%7C02%8C%8E21%93%FA-%8BL%98^&HUID=126689&KGNO=324&FINO=2458)）。
