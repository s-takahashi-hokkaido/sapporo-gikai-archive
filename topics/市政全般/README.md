市長は2期目の施政方針で、市民自治を根本に据え、まちづくりのプランと行財政改革のプランを策定すると述べた（[2007-06-07](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=1&FYY=2007&TYY=2007&TITL_SUBT=%95%BD%90%AC%82P%82X%94N%91%E6%81@%82Q%89%F1%92%E8%97%E1%89%EF%81%7C06%8C%8E07%93%FA-01%8D%86&HUID=89952&KGNO=252&FINO=1851)）。計画は平成19年度から22年度の4年間で、成果指標66項目、総事業費4,516億円、一般財源401億円とされた（[2007-10-11](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2007&TYY=2007&TITL_SUBT=%95%BD%90%AC%82P%82X%94N%81i%8F%ED%94C%81j%8D%E0%90%AD%8Es%96%AF%88%CF%88%F5%89%EF%81%7C10%8C%8E11%93%FA-%8BL%98^&HUID=92582&KGNO=245&FINO=1910)）。自由民主党議員会は目標到達の少なさを指摘し、計画期間の終了後に空白を置かず次期中期計画を策定するよう求めたが、市長は次期計画の方針は次の任期の市長の判断にゆだねるのが相当だと答えた（[2007-12-04](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=1&FYY=2007&TYY=2007&TITL_SUBT=%95%BD%90%AC%82P%82X%94N%91%E6%81@%82S%89%F1%92%E8%97%E1%89%EF%81%7C12%8C%8E04%93%FA-03%8D%86&HUID=95341&KGNO=261&FINO=1942)、[2007-10-02](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=1&FYY=2007&TYY=2007&TITL_SUBT=%95%BD%90%AC%82P%82X%94N%91%E6%81@%82R%89%F1%92%E8%97%E1%89%EF%81%7C10%8C%8E02%93%FA-02%8D%86&HUID=91818&KGNO=258&FINO=1894)）。マニフェストについて、2010年6月の代表質問では76項目のうち59項目が達成または達成見込みとされ、市長は効果の評価を今後の課題とした（[2010-06-01](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=1&FYY=2010&TYY=2010&TITL_SUBT=%95%BD%90%AC%82Q%82Q%94N%91%E6%81@%82Q%89%F1%92%E8%97%E1%89%EF%81%7C06%8C%8E01%93%FA-02%8D%86&HUID=120826&KGNO=310&FINO=2351)）。アートヴィレッジへの宿泊施設誘致は、政策企画部長が事実上達成が大変困難だと答えた（[2009-10-14](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2009&TYY=2009&TITL_SUBT=%95%BD%90%AC%82Q%82P%94N%91%E6%88%EA%95%94%8C%88%8EZ%93%C1%95%CA%88%CF%88%F5%89%EF%81%7C10%8C%8E14%93%FA-03%8D%86&HUID=113646&KGNO=296&FINO=2240)）。
