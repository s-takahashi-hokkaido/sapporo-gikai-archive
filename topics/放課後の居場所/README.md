- 民間学童の助成水準：2009年1月に子ども育成部長は「安定的で継続した助成を行ってまいりたい」と答えた（[2009-01-22](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2009&TYY=2009&TITL_SUBT=%95%BD%90%AC%82Q%82P%94N%81i%8F%ED%94C%81j%95%B6%8B%B3%88%CF%88%F5%89%EF%81%7C01%8C%8E22%93%FA-%8BL%98^&HUID=106728&KGNO=281&FINO=2112)）。2017年から2019年にかけては「まずは、現在の助成を継続できるように」、2022年10月には「まずは現在の助成を継続できるよう適切に対応してまいりたいと考えております。」と答えた（[2017-10-25](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2017&TYY=2017&TITL_SUBT=%95%BD%90%AC%82Q%82X%94N%91%E6%88%EA%95%94%8C%88%8EZ%93%C1%95%CA%88%CF%88%F5%89%EF%81%7C10%8C%8E25%93%FA-08%8D%86&HUID=193365&KGNO=447&FINO=3404)、[2019-02-21](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2019&TYY=2019&TITL_SUBT=%95%BD%90%AC%82R%82P%94N%81i%8F%ED%94C%81j%95%B6%8B%B3%88%CF%88%F5%89%EF%81%7C02%8C%8E21%93%FA-%8BL%98^&HUID=203826&KGNO=473&FINO=3579)、[2022-10-26](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2022&TYY=2022&TITL_SUBT=%97%DF%98a%81@%82S%94N%91%E6%88%EA%95%94%8C%88%8EZ%93%C1%95%CA%88%CF%88%F5%89%EF%81%7C10%8C%8E26%93%FA-08%8D%86&HUID=234502&KGNO=566&FINO=4166)）。2025年10月にも「引き続き、継続していくことを最優先に努めてまいりたいと考えております」とし、10年以上にわたり現行助成の継続を軸とする答弁が続いている（[2025-10-23](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2025&TYY=2025&TITL_SUBT=%97%DF%98a%81@%82V%94N%91%E6%88%EA%95%94%8C%88%8EZ%93%C1%95%CA%88%CF%88%F5%89%EF%81%7C10%8C%8E23%93%FA-07%8D%86&HUID=257548&KGNO=684&FINO=4637)）。
- 障がい児加算・指導員処遇・小規模補助：2011年10月に「慎重な議論が必要と考えております」、2013年9月に「国の動向を引き続き注視してまいります」と答えた（[2011-10-18](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2011&TYY=2011&TITL_SUBT=%95%BD%90%AC%82Q%82R%94N%91%E6%88%EA%95%94%8C%88%8EZ%93%C1%95%CA%88%CF%88%F5%89%EF%81%7C10%8C%8E18%93%FA-04%8D%86&HUID=132468&KGNO=337&FINO=2556)、[2013-09-26](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=1&FYY=2013&TYY=2013&TITL_SUBT=%95%BD%90%AC%82Q%82T%94N%81@%91%E6%82R%89%F1%92%E8%97%E1%89%EF%81%7C09%8C%8E26%93%FA-03%8D%86&HUID=154765&KGNO=372&FINO=2837)）。2021年3月には「さらなる財政措置について国に要望してまいりたいと考えております」、2025年2月に副市長は「引き続き他の政令市とともに要望してまいりたいと考えるところでございます」と、国の動向や国への要望を軸とする答弁が続いている（[2021-03-26](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2021&TYY=2021&TITL_SUBT=%97%DF%98a%81@%82R%94N%91%E6%88%EA%95%94%97%5C%8EZ%93%C1%95%CA%88%CF%88%F5%89%EF%81%7C03%8C%8E26%93%FA-09%8D%86&HUID=221855&KGNO=524&FINO=3900)、[2025-02-21](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=1&FYY=2025&TYY=2025&TITL_SUBT=%97%DF%98a%81@%82V%94N%91%E6%81@%82P%89%F1%92%E8%97%E1%89%EF%81%7C02%8C%8E21%93%FA-04%8D%86&HUID=251315&KGNO=653&FINO=4516)）。
