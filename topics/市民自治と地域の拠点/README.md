- 住民投票について、2022年6月に市民自治推進室長は「規模や費用、効果など、様々な課題があるものと考えているところでございます」と答えたが、2023年2月に市長は「住民投票の仕組みということについて、札幌市としてこのことを進めていかなければいけない」と前向きな表現に変わった（[2022-06-02](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2022&TYY=2022&TITL_SUBT=%97%DF%98a%81@%82S%94N%81i%8F%ED%94C%81j%8Co%8D%CF%8A%CF%8C%F5%88%CF%88%F5%89%EF%81%7C06%8C%8E02%93%FA-%8BL%98^&HUID=231659&KGNO=550&FINO=4112)、[2023-02-22](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=1&FYY=2023&TYY=2023&TITL_SUBT=%97%DF%98a%81@%82T%94N%91%E6%81@%82P%89%F1%92%E8%97%E1%89%EF%81%7C02%8C%8E22%93%FA-04%8D%86&HUID=235782&KGNO=569&FINO=4195)）。その後、2023年10月に市民自治推進室長は「引き続き、他都市の事例を調査研究するとともに、必要に応じ、有識者の意見を聞くなどして検討してまいりたいと考えております」、2025年2月に市長は「引き続き議会とも十分に協議をしながら検討をしてまいりたいと考えております」と答え、検討の段階にとどまっている（[2023-10-19](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2023&TYY=2023&TITL_SUBT=%97%DF%98a%81@%82T%94N%81i%8F%ED%94C%81j%8D%E0%90%AD%8Es%96%AF%88%CF%88%F5%89%EF%81%7C10%8C%8E19%93%FA-%8BL%98^&HUID=241431&KGNO=572&FINO=4307)、[2025-02-21](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=1&FYY=2025&TYY=2025&TITL_SUBT=%97%DF%98a%81@%82V%94N%91%E6%81@%82P%89%F1%92%E8%97%E1%89%EF%81%7C02%8C%8E21%93%FA-04%8D%86&HUID=251315&KGNO=653&FINO=4516)）。
- まちづくりセンターの自主運営化について、2008年3月の「本年秋ごろから希望する地域において実施することを考えております」以降、地域の希望を前提とする姿勢は変わらなかった（[2008-03-21](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2008&TYY=2008&TITL_SUBT=%95%BD%90%AC%82Q%82O%94N%91%E6%88%EA%95%94%97%5C%8EZ%93%C1%95%CA%88%CF%88%F5%89%EF%81%7C03%8C%8E21%93%FA-08%8D%86&HUID=98577&KGNO=269&FINO=1991)、[2010-02-24](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=1&FYY=2010&TYY=2010&TITL_SUBT=%95%BD%90%AC%82Q%82Q%94N%91%E6%81@%82P%89%F1%92%E8%97%E1%89%EF%81%7C02%8C%8E24%93%FA-04%8D%86&HUID=117572&KGNO=302&FINO=2294)）。2011年10月には「今後も自主運営センターをふやす方向で変更はない」、2013年10月には「選択肢の一つとして推進してまいりたい」との答弁があり、2016年3月に数値目標の設定をやめた後も市民自治推進室長は「その方針は現在も変わっておりません」と答えた（[2011-10-31](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2011&TYY=2011&TITL_SUBT=%95%BD%90%AC%82Q%82R%94N%91%E6%88%EA%95%94%8C%88%8EZ%93%C1%95%CA%88%CF%88%F5%89%EF%81%7C10%8C%8E31%93%FA-08%8D%86&HUID=133889&KGNO=337&FINO=2565)、[2013-10-18](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2013&TYY=2013&TITL_SUBT=%95%BD%90%AC%82Q%82T%94N%91%E6%88%EA%95%94%8C%88%8EZ%93%C1%95%CA%88%CF%88%F5%89%EF%81%7C10%8C%8E18%93%FA-06%8D%86&HUID=157142&KGNO=373&FINO=2861)、[2016-03-17](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2016&TYY=2016&TITL_SUBT=%95%BD%90%AC%82Q%82W%94N%91%E6%88%EA%95%94%97%5C%8EZ%93%C1%95%CA%88%CF%88%F5%89%EF%81%7C03%8C%8E17%93%FA-07%8D%86&HUID=180397&KGNO=420&FINO=3199)）。
- 区の機能強化について、2007年6月に地域振興部長が「区の機能強化の方策につきまして、区民協議会の検討と並行しながら庁内関係部局とも検討を進めてまいりたいと考えております」と答えて以降、2014年12月に市長は「区の役割や、あるいは機能の拡充について検討を加えてまいりたい」、2017年12月に「区の機能やマネジメント力の強化に向けて検討を進めてまいりたい」と答え、検討するとの答弁が続いた（[2007-06-20](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2007&TYY=2007&TITL_SUBT=%95%BD%90%AC%82P%82X%94N%91%E6%88%EA%95%94%8Bc%88%C4%90R%8D%B8%93%C1%95%CA%88%CF%88%F5%89%EF%81%7C06%8C%8E20%93%FA-02%8D%86&HUID=90259&KGNO=253&FINO=1860)、[2014-12-04](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=1&FYY=2014&TYY=2014&TITL_SUBT=%95%BD%90%AC%82Q%82U%94N%81@%91%E6%82S%89%F1%92%E8%97%E1%89%EF%81%7C12%8C%8E04%93%FA-03%8D%86&HUID=168433&KGNO=392&FINO=3014)、[2017-12-05](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=1&FYY=2017&TYY=2017&TITL_SUBT=%95%BD%90%AC%82Q%82X%94N%91%E6%81@%82S%89%F1%92%E8%97%E1%89%EF%81%7C12%8C%8E05%93%FA-02%8D%86&HUID=193792&KGNO=449&FINO=3415)）。2026年6月にも行政部長は、区が主体的に地域課題を解決できるよう努めると答えた（[2026-06-18](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2026&TYY=2026&TITL_SUBT=%97%DF%98a%81@%82W%94N%91%E5%93s%8Es%90%C5%8D%E0%90%AD%90%A7%93x%81E%82c%82w%90%84%90i%92%B2%8D%B8%93%C1%95%CA%88%CF%88%F5%89%EF%81%7C06%8C%8E18%93%FA-%8BL%98^&HUID=260643&KGNO=706&FINO=4729)）。
- 総合区について、2014年5月に副市長は「現状におきましては札幌市にとってふさわしい制度であるとは考えていない」とし、2016年3月に地域振興部長も「札幌市としては総合区制度の導入を考えていないところであります」と答えた（[2014-05-22](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=1&FYY=2014&TYY=2014&TITL_SUBT=%95%BD%90%AC%82Q%82U%94N%91%E6%81@%82Q%89%F1%92%E8%97%E1%89%EF%81%7C05%8C%8E22%93%FA-03%8D%86&HUID=163700&KGNO=386&FINO=2951)、[2016-03-17](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2016&TYY=2016&TITL_SUBT=%95%BD%90%AC%82Q%82W%94N%91%E6%88%EA%95%94%97%5C%8EZ%93%C1%95%CA%88%CF%88%F5%89%EF%81%7C03%8C%8E17%93%FA-07%8D%86&HUID=180404&KGNO=420&FINO=3199)）。2026年6月に大地さっぽろが総合区への見解を問うたが、記録上見解は示されていない（[2026-06-18](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2026&TYY=2026&TITL_SUBT=%97%DF%98a%81@%82W%94N%91%E5%93s%8Es%90%C5%8D%E0%90%AD%90%A7%93x%81E%82c%82w%90%84%90i%92%B2%8D%B8%93%C1%95%CA%88%CF%88%F5%89%EF%81%7C06%8C%8E18%93%FA-%8BL%98^&HUID=260643&KGNO=706&FINO=4729)）。
- 区民センター等の指定管理者選定で、地域振興部長は2009年4月の「選定委員１人当たりの持ち点1,000点中の10点程度は必要になるのではないかと考えているところでございます」から、2009年6月に「40点までは配慮したい、このように考えてございます」に変わった（[2009-04-24](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2009&TYY=2009&TITL_SUBT=%95%BD%90%AC%82Q%82P%94N%81i%8F%ED%94C%81j%8D%E0%90%AD%8Es%96%AF%88%CF%88%F5%89%EF%81%7C04%8C%8E24%93%FA-%8BL%98^&HUID=110581&KGNO=282&FINO=2176)、[2009-06-02](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=3&FYY=2009&TYY=2009&TITL_SUBT=%95%BD%90%AC%82Q%82P%94N%81i%8F%ED%94C%81j%8D%E0%90%AD%8Es%96%AF%88%CF%88%F5%89%EF%81%7C06%8C%8E02%93%FA-%8BL%98^&HUID=111455&KGNO=282&FINO=2193)）。その後、副市長は2013年2月に「非公募とすることについて検討してまいります」と答え、同年に非公募を可能にする条例改正が行われた（[2013-02-18](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=1&FYY=2013&TYY=2013&TITL_SUBT=%95%BD%90%AC%82Q%82T%94N%91%E6%81@%82P%89%F1%92%E8%97%E1%89%EF%81%7C02%8C%8E18%93%FA-02%8D%86&HUID=147848&KGNO=363&FINO=2750)、[2013-06-12](https://sapporo.gijiroku.com/voices/cgi/voiweb.exe?ACT=200&KENSAKU=0&KGTP=1&FYY=2013&TYY=2013&TITL_SUBT=%95%BD%90%AC%82Q%82T%94N%91%E6%81@%82Q%89%F1%92%E8%97%E1%89%EF%81%7C06%8C%8E12%93%FA-05%8D%86&HUID=153771&KGNO=370&FINO=2817)）。
