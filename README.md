# 札幌市議会アーカイブ

札幌市議会の会議録（本会議と委員会、2007年〜2026年6月ごろ）を、AI で話題ごと・区ごとに整理したもの。53の話題について20年の流れと現状を、10の区について区にかかる議会のやり取りを、会議録へのリンク付きで読める。

**札幌市議会の公式のものではない。** 個人が作った非公式の資料である。

## 使う前に

> **要旨は AI の要約で、原文ではない。** 数字や答弁を人前で使う前に、文の後ろの日付のリンクから会議録の原文を開いて確かめる。

- 文の後ろの日付（「（2024-05-27）」など）は、札幌市議会会議録検索システムの、その発言へのリンク
- 「［要確認］」の付いた文は、数字や引用を、もとの記録や会議録の原文と機械で照らして確かめられなかったもの。誤りとは限らないが、とくに原文で確かめる。一覧は [要確認.md](topics/%E8%A6%81%E7%A2%BA%E8%AA%8D.md)
- 「会派ごとの立場」も AI の要約。会派が自ら書いたものではない
- 地域（区）も AI が付けた。「全市」の話の中で区に具体的に触れたものにも、その区が付いている
- 会議録は2026年6月ごろの分まで（委員会は8月の一部まで）。会議録検索システムに載るまで数か月かかるので、それより新しい動きは入っていない
- この資料を使って生じたことについて、作った人は責任を負わない

## 読むのは2か所だけ

| 入口 | 中身 |
|---|---|
| [話題ごと（topics）](topics/README.md) | 53の話題の一覧（雪、子育て、交通、福祉、まちづくり など16の分野）。話題ごとに、現状、20年の経緯、会派ごとの立場、市の答弁の変化、未解決の論点 |
| [区ごと（areas）](areas/README.md) | 10区の入口。区にかかる記録を、話題ごと・地名ごとに日付順に並べたもの。最近の記録 |

区の入口: [中央区](areas/%E4%B8%AD%E5%A4%AE%E5%8C%BA/README.md)、[北区](areas/%E5%8C%97%E5%8C%BA/README.md)、[東区](areas/%E6%9D%B1%E5%8C%BA/README.md)、[白石区](areas/%E7%99%BD%E7%9F%B3%E5%8C%BA/README.md)、[厚別区](areas/%E5%8E%9A%E5%88%A5%E5%8C%BA/README.md)、[豊平区](areas/%E8%B1%8A%E5%B9%B3%E5%8C%BA/README.md)、[清田区](areas/%E6%B8%85%E7%94%B0%E5%8C%BA/README.md)、[南区](areas/%E5%8D%97%E5%8C%BA/README.md)、[西区](areas/%E8%A5%BF%E5%8C%BA/README.md)、[手稲区](areas/%E6%89%8B%E7%A8%B2%E5%8C%BA/README.md)

ほかのフォルダ（話題×4年のまとめ、記録の本体、作るためのプログラム など）は、上の2か所の材料。読まなくてよい。

## 使い方の例

### 自分の区から調べる

1. 区の入口を開く（たとえば北区）
2. 「話題ごと」の表から、気になる話題（たとえば「生活道路の排雪」）を開く。その区にかかる質問と答弁が、日付順に並んでいる。表の「20年の経緯」からは、札幌市全体の流れも読める
3. 使いたい記録の［会議録］のリンクから原文を開き、数字や答弁を確かめる

### 話題の20年の流れをつかむ

1. 話題の一覧から話題を開く
2. 「現状」「20年の経緯」「市の答弁の変化」を読む。「市は◯年から『検討する』と答え続けている」のような流れが、出典付きでわかる
3. 使いたい文の後ろの日付のリンクから、会議録の原文を確かめる

### AI に読ませて質問する

1. 下の「ダウンロード」から ZIP を取り、展開する
2. 使う話題のファイル（`topics` の中の話題のフォルダの README.md）や、区のフォルダ（`areas` の中）を、AI（Claude のプロジェクトなど）に入れる。全部は大きすぎるので、使うものを選んで入れる
3. 「北区の除雪について、市の答弁がどう変わったか、日付付きで教えて」のように聞く。AI の答えも、会議録の原文で確かめる

## ダウンロード

- GitHub の画面で、そのまま読める（スマホでも読める）
- 手元に置くなら ZIP をダウンロードする: <https://github.com/s-takahashi-hokkaido/sapporo-gikai-archive/archive/refs/heads/main.zip>（約40MB。展開すると約190MB）
- 展開したら、[Obsidian](https://obsidian.md/) か [VS Code](https://code.visualstudio.com/) の「フォルダを開く」で開く。表とリンクがそのまま使える。メモ帳で開くと表が崩れ、リンクも効かない

## 引用するとき

出典の書き方の例:

> 札幌市議会アーカイブ（非公式）「除排雪の体制と費用」、https://github.com/s-takahashi-hokkaido/sapporo-gikai-archive

数字や答弁を引くときは、会議録の原文を開いて確かめ、会議録（会議名と日付）も出典に書く。たとえば「札幌市議会 令和6年第2回定例会（2024年5月27日）」。
